# 跑马灯系统架构设计文档

## 1. 系统概述

### 1.1 项目背景
本系统是一个基于Linux平台的高性能LED跑马灯显示系统，支持文字滚动、天气预报、世界时间显示等功能，适用于广告展示、信息发布等场景。

### 1.2 技术特点
- 基于DRM/KMS直接渲染，无需X11/Wayland
- 使用EGL/GLES2进行硬件加速渲染
- 支持FreeType字体渲染，支持中文显示
- 支持MQTT远程控制
- 支持透明度调节和多层叠加
- 60FPS流畅显示

## 2. 系统架构

                            ↓
┌─────────────────────────────────────────────────────────┐

### 2.2 核心模块设计

#### 2.2.1 DRM/KMS显示管理模块
**功能职责：**
- 管理显示设备（/dev/dri/card0）
- 查找和配置连接器（Connector）
- 管理CRTC和显示模式
- 支持Plane叠加显示
- 处理页面翻转事件

**核心组件：**
- `drm_find_connector()`: 查找已连接的显示设备
- `drm_find_crtc_for_connector()`: 为连接器查找合适的CRTC
- `add_fb_for_bo()`: 为GBM缓冲对象创建帧缓冲
- `try_set_plane_alpha()`: 设置Plane透明度

#### 2.2.2 EGL/GLES2渲染模块
**功能职责：**
- 初始化EGL显示环境
- 创建OpenGL ES 2.0上下文
- 管理着色器程序
- 处理缓冲交换

**核心组件：**
- EGL上下文管理：显示、表面、上下文初始化
- 着色器编译和链接
- 纹理管理和渲染管线

#### 2.2.3 文本渲染模块
**功能职责：**
- FreeType字体库初始化
- UTF-8文本解析
- 字形渲染和纹理生成
- 文本宽度计算
- 字距调整（Kerning）

**核心组件：**
- `font_init()`: 初始化FreeType库
- `render_text_gles_ft()`: 渲染UTF-8文本
- `compute_text_width()`: 计算文本宽度
- `utf8_next()`: UTF-8字符解析

#### 2.2.4 跑马灯控制模块
**功能职责：**
- 跑马灯配置管理
- 滚动动画控制
- 文本位置计算
- 帧率同步

**配置参数：**
```c
typedef struct {
    std::string text;           // 显示文本
    int font_size;              // 字体大小
    float text_color[4];        // 文本颜色
    float bg_color[4];          // 背景颜色
    int position;               // 显示位置
    int scroll_speed;           // 滚动速度
    bool font_bold;             // 字体粗细
    int text_align;             // 文本对齐
    bool show_weather;          // 显示天气
    bool show_world_time;       // 显示世界时间
    int weather_position;       // 天气位置
} MarqueeConfig;
```

#### 2.2.5 天气显示模块
**功能职责：**
- 天气数据管理
- 天气信息渲染
- 温度和湿度显示

**数据结构：**
```c
typedef struct {
    std::string city;           // 城市名称
    std::string region;         // 区域
    std::string weather;        // 天气状况
    int temp;                   // 温度
    int humidity;               // 湿度
} WeatherData;
```

#### 2.2.6 世界时间模块
**功能职责：**
- 多城市时间管理
- 时区转换
- 时间格式化显示

**数据结构：**
```c
typedef struct {
    std::string name;           // 城市名称
    int timezone;               // 时区偏移
    bool enabled;               // 是否启用
} CityTime;
```

#### 2.2.7 MQTT控制模块
**功能职责：**
- MQTT客户端初始化
- 消息订阅和接收
- 远程配置更新
- 线程安全的配置管理

**核心组件：**
- `init_mqtt()`: 初始化MQTT客户端
- `on_mqtt_message()`: 消息回调处理
- `handle_mqtt_message()`: JSON配置解析

## 3. 数据流设计

### 3.1 渲染流程

```
1. 初始化阶段
   ├─ DRM设备打开和配置
   ├─ GBM设备创建
   ├─ EGL上下文初始化
   ├─ 着色器编译
   └─ 字体库加载

2. 渲染循环
   ├─ 清空缓冲区
   ├─ 渲染背景
   ├─ 渲染天气信息（如果启用）
   ├─ 渲染世界时间（如果启用）
   ├─ 渲染跑马灯文本
   ├─ 交换缓冲区
   ├─ 获取GBM缓冲对象
   ├─ 创建DRM帧缓冲
   ├─ 显示到屏幕
   └─ 帧率控制

3. 清理阶段
   ├─ 释放资源
   ├─ 关闭设备
   └─ 退出程序
```

### 3.2 MQTT控制流程

```
1. MQTT初始化
   ├─ 创建MQTT客户端
   ├─ 设置回调函数
   ├─ 连接到Broker
   └─ 订阅控制主题

2. 消息处理
   ├─ 接收JSON消息
   ├─ 解析配置参数
   ├─ 更新配置（线程安全）
   └─ 触发配置更新标志

3. 配置应用
   ├─ 检查更新标志
   ├─ 应用新配置
   └─ 清除更新标志
```

## 4. 技术实现细节

### 4.1 编译依赖

```bash
# 基础依赖
sudo apt install libdrm-dev libgbm-dev libegl1-mesa-dev libgles2-mesa-dev

# 字体支持
sudo apt install libfreetype6-dev

# MQTT支持（可选）
sudo apt install libmosquitto-dev

# 编译命令
g++ -o test test.cpp $(pkg-config --cflags --libs gbm egl glesv2 libdrm freetype2) -ldl

# 带MQTT支持
g++ -DUSE_MQTT -o test test.cpp $(pkg-config --cflags --libs gbm egl glesv2 libdrm freetype2 mosquitto) -ldl
```

### 4.2 运行参数

```bash
# 基础运行
./test -p 79 -W 400 -H 400 -X 100 -Y 100

# 完整参数
./test --plane 79 --win-w 1920 --win-h 1080 --x 0 --y 0 --alpha 1.1

# 跑马灯模式
./test -p 173 -W 1920 -H 100 -pos 0 -ss 8 -fb -ta 0

# 世界时间模式
./test -p 173 -W 800 -H 400 -dm 1 -fs 32

# 天气预报模式
./test -p 173 -W 800 -H 400 -dm 2 -fs 32

# 组合模式
./test -p 173 -W 1920 -H 100 -we -wt -t "这是一段测试文字"

# MQTT模式
./test -p 173 -W 1920 -H 100 -we -wt -wp 0 -mh localhost -mp 1883
```

### 4.3 性能优化

1. **帧率控制**
   - 使用高精度时钟同步
   - 目标帧率：60FPS
   - 自适应帧间隔调整

2. **内存管理**
   - GBM缓冲对象重用
   - 纹理缓存优化
   - 及时释放不用的资源

3. **渲染优化**
   - 批量渲染文本字符
   - 使用VBO减少GPU传输
   - 着色器优化

4. **线程安全**
   - 使用互斥锁保护配置
   - 避免渲染线程阻塞
   - 原子操作更新标志
