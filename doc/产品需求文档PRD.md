# 跑马灯系统产品需求文档 (PRD)

## 文档信息
- **项目名称**: LED跑马灯显示系统
- **文档版本**: v1.0
- **创建日期**: 2026-06-15
- **文档状态**: 正式发布

## 1. 产品概述

### 1.1 产品背景
随着数字化广告和信息发布需求的增长，传统的LED显示屏控制方式存在操作复杂、内容更新困难、显示效果单一等问题。本产品旨在提供一个高性能、易用、功能丰富的LED跑马灯显示系统，支持多种显示模式和远程控制。

### 1.2 产品定位
- **目标用户**: 广告公司、商场、车站、机场等需要信息发布的场所
- **产品类型**: 专业级LED显示控制系统
- **应用场景**: 广告展示、信息发布、时间显示、天气播报等

### 1.3 核心价值
- **高性能**: 60FPS流畅显示，硬件加速渲染
- **易用性**: 支持远程控制，实时内容更新
- **多功能**: 支持文字、天气、时间等多种显示模式
- **稳定性**: 基于Linux系统，长期稳定运行

## 2. 产品功能

### 2.1 核心功能

#### 2.1.1 跑马灯文字显示
**功能描述**: 支持滚动文字显示，可配置滚动速度、字体大小、颜色等参数。

**功能需求**:
- 支持UTF-8编码，包含中文字符
- 可调节字体大小（16-128像素）
- 可调节滚动速度（1-20级）
- 支持自定义文本颜色（RGBA）
- 支持自定义背景颜色
- 支持左对齐、居中、右对齐
- 支持字体粗细调节

**优先级**: P0（核心功能）

#### 2.1.2 天气信息显示
**功能描述**: 显示当前天气信息，包括城市、天气状况、温度、湿度等。

**功能需求**:
- 显示城市名称和区域
- 显示天气状况（晴、阴、雨等）
- 显示当前温度（摄氏度）
- 显示空气湿度
- 支持多个城市切换
- 天气位置可配置

**优先级**: P1（重要功能）

#### 2.1.3 世界时间显示
**功能描述**: 同时显示多个城市的当前时间，支持时区转换。

**功能需求**:
- 支持至少8个主要城市
- 显示城市名称和当地时间
- 自动时区转换
- 可启用/禁用特定城市
- 时间格式：HH:MM
- 支持自定义城市列表

**优先级**: P1（重要功能）

#### 2.1.4 远程控制
**功能描述**: 通过MQTT协议进行远程控制，支持实时配置更新。

**功能需求**:
- 支持MQTT协议连接
- 支持JSON格式配置
- 支持文本内容更新
- 支持显示参数调整
- 支持功能开关控制
- 支持多客户端连接

**优先级**: P0（核心功能）

### 2.2 高级功能

**优先级**: P1（重要功能）

#### 2.2.3 定时任务
**功能描述**: 支持定时切换显示内容和模式。

**优先级**: P3（未来功能）

## 3. 技术需求

### 3.1 性能需求
- **帧率**: 保持60FPS稳定显示
- **延迟**: 控制响应延迟<100ms
- **内存**: 运行内存占用<256MB
- **CPU**: CPU占用率<30%（正常显示时）

### 3.2 兼容性需求
- **操作系统**: Linux（Ubuntu 20.04+推荐）
- **硬件**: 支持DRM/KMS的GPU
- **图形**: 支持OpenGL ES 2.0
- **分辨率**: 支持1920x1080及以下分辨率

### 3.3 可靠性需求
- **稳定性**: 7x24小时连续运行
- **恢复时间**: 异常重启后<10秒恢复
- **数据完整性**: 配置数据不丢失
- **错误处理**: 优雅的错误处理和恢复

### 3.4 安全性需求
- **访问控制**: 支持用户认证
- **数据传输**: 支持加密传输
- **权限管理**: 最小权限原则
- **审计日志**: 关键操作审计

- **EGL**: Embedded-System Graphics Library，嵌入式系统图形库
- **GLES**: OpenGL for Embedded Systems，嵌入式系统OpenGL
